02 / HOW WE WORK

我们怎么整理材料

Agent 负责整理材料和推进研究。案件记录、证据规则和检查脚本保留每一步的依据。

  1. 01

    认清研究对象

    区分人物、品牌、运营公司和控股主体。先确定是谁，再讨论发生了什么。

  2. 02

    重建关键选择

    把事件、关系和当时的环境放在一起。记录实际做了什么，也记录当时存在的其他选择。

  3. 03

    寻找支持与反证

    核对来源谱系，区分事实、自述与推断；留下能推翻当前解释的新证据条件。

  4. 04

    交付可读的研究

    时间线、决策与来源共同呈现。无法确认的结论，继续保留为问题。

研究边界

没有证据的部分，
标成未解决。
