02 / HOW WE WORK

理解转折，
也保留解释的边界。

Agent 组织材料与研究；案件记录、证据规则和校验脚本，让过程留下可检查的结果。

  1. 01

    认清研究对象

    区分人物、品牌、运营公司和控股主体。先确定是谁，再讨论发生了什么。

  2. 02

    重建关键选择

    连接事件、关系与时代条件；既问做了什么，也问当时还有哪些路可走。

  3. 03

    寻找支持与反证

    核对来源谱系，区分事实、自述与推断；留下能推翻当前解释的新证据条件。

  4. 04

    交付可读的研究

    时间线、决策与来源共同呈现。无法确认的结论，继续保留为问题。
