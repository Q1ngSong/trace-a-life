# Wave 1 · 本地中文研究页

本方向把同一个 renderer 接到两种已保存输入：完整 `case.json`，以及发布构建产生的 `public-research/1` `results.json`。页面只投影已有字段，不补写外部事实。

## 本次交付

- `render_case.py` 自动识别并解包本地 `results.json`；
- 来源台账用原生 `details` 展开元数据和已有逐字引文；没有引文时明确显示“当前快照只保留来源登记，未附逐字引文”；
- 主张显示“已引用引文 / 已登记来源，未附逐字引文 / 待补来源与引文”；
- 未解决问题可展开查看已检索内容、下一步查询、影响和关联主张；
- 发布 allowlist 保留完整案件中已经存在的短引文，不为公开快照生成新引文。

## 验证范围

页面由 `website/cases/*/results.json` 在本地重新渲染；静态检查确认每个案例包含来源展开、缺口展开和研究状态。浏览器/移动端截图未在本沙箱中完成：本地 HTTP 端口受到权限限制，Cua 预览也未能启动，因此只报告 HTML 解析和构建检查结果。
